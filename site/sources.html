Tier definitions

  • Tier A — Primary/official government or regulator source, or the issuer's own SEC filing. Directly retrieved and quoted in this session.
  • Tier B — Official industry/standard-setter or regional government-agency analysis (e.g. LAEDC via SCAG). Retrieved and quoted.
  • Tier C — Secondary or commercial source. Used only for context; never used to set a hard value. Flagged for review.
  • Tier D — Owner-supplied document (lease, rent roll, appraisal). NOT YET RECEIVED. Everything depending on it is flagged UNVERIFIED.

Sources that were deliberately NOT used

Tier C sources are excluded from every calculation

Two secondary commercial sources appear in the register with tier C — a CoStar net-lease cap-rate summary and a Nareit fact sheet. Both were reachable only as search-index snippets or paywalled summaries. Neither is used as a model input. The cap-rate anchor actually used is a transacted cash yield disclosed to the SEC by the largest listed net-lease buyer, which is a stronger instrument and is reproducible by anyone who opens the filing.
