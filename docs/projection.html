The core identity

Value = NOI ÷ cap rate. Only two things can move value. For this asset the NOI is contractually fixed by a NNN lease, so the landlord has almost no lever there. The cap rate is therefore the dominant variable — and remaining lease term feeds directly into it, because net-lease buyers pay for the durability of cash flow. That is why time itself is a cost here.

Reproducibility

Run python3 model/projection_model.py. The RNG seed is fixed at 20261106, so the output JSON is byte-identical on every run. The engine uses no third-party libraries and no network access.
