Method, sources & verification

How every number on this site was checked

195 sourced data points. Each carries a source link, a source tier and a status. Nothing is marked verified without a resolving official source; nothing unconfirmed is filled in.

Reproducible. python3 model/build_facts.py regenerates the dataset and asserts that every unverified row is genuinely blank. python3 model/projection_model.py regenerates the model with a fixed seed. python3 model/build_site.py rebuilds this site and fails if any internal link is broken.

Verification procedure actually performed

  1. Each metric was retrieved from a resolving official page or CSV endpoint on 2026-11-06.
  2. The period or vintage is recorded per row (e.g. "Sep 2026", "V2025", "FY2025", "ACS 2020–2024"). Rows are never compared across incompatible vintages without saying so.
  3. Percentages were recomputed from the raw series, not copied from commentary:
    • CPI year over year = 336.298 / 324.245 − 1 = +3.72%
    • LA metro payrolls, Sep 2019 → Sep 2026 = 6,282.1 / 6,236.7 − 1 = +0.73% over seven years
    • LA metro payrolls, Oct 2024 peak → Sep 2026 = 6,282.1 / 6,359.6 − 1 = −1.22%
    • Franchised share = 1,966 / 2,115 = 93.0%
  4. Automated assertions in build_facts.py: every verified row must carry a URL, and every unverified row must have an empty value. The build fails otherwise.
  5. Automated assertions in build_site.py: every internal link must resolve to a page that was actually emitted.

Known limitations

#LimitationConsequence
L1No street address or APN supplied, by design.Parcel-level hazard, zoning, assessed value and school assignment are unverified.
L2The lease document was not supplied. "NNN" and "expiring 2030–2035" are as described, not verified.The model parameterises these and shows sensitivity instead of asserting them.
L3Current rent, NOI and basis were not supplied.The model is normalised per $1.00 of current NOI so no disclosure is required.
L4api.census.gov required a key that was not available.ACS data were taken from Census QuickFacts (same source data, different access path).
L5California DOF projections are distributed as .xlsx.Projections were not machine-verified; Census V2025 estimates are used instead.
L6FEMA National Risk Index API returned HTTP 500.County hazard scores are not reported.
L7Cap-rate data are Tier 3 (a brokerage).Treated as directional and badged on every row.
