Verification

What the automated gate enforces, what it cannot certify, and the repository findings that changed this build.

Verification status: PASS. 1018 automated checks passed.

The checks are the gate, not a certificate. They enforce that every published row has a resolving official source and a locator, that every unverified row is blank, that links resolve, and that no personal identifier appears. They cannot certify that a number was transcribed correctly — only a human re-reading the cited page can do that, which is why the locator column exists.

Repository review findings

The repository was reviewed line by line. The findings that matter are on the Flagged for review page. Three are worth stating here because they affected the build itself:

The shared CI check had been failing on main since 2026-11-08

The audit script fingerprinted the append-only coordination log, so any session that obeyed the board rule invalidated the committed snapshot and the gate could never pass again. Diagnosed by replaying the workflow steps locally, then fixed so that the log is still scanned on every line but its fingerprint is not asserted. Verified by running the workflow steps twice from a clean tree with an empty git status both times.

A hazard citation used by earlier sessions returns 404

The earlier USGS address no longer resolves. The live record was located, read, and is the only hazard citation used here. The values are unchanged: 60%, 46%, 31%.

Several published pages contain dollar conclusions built on assumed rent

The historical root workbook states an assumption converting a percentage of system average unit volume into a rent figure, then reports precise wealth differences from it. Those pages are preserved for audit and are clearly labelled as historical. They are not endorsed, and this workbook does not use them.

Internal decision support. Not an appraisal, a tax opinion, legal advice or an offer. No street address, parcel number, owner name, loan number or account appears anywhere on this site.
