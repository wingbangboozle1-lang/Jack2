Flagged for review

Everything that could not be confirmed from an official source, with the evidence and what would close each gap.

This page is the point of the exercise, not an appendix. Everything that could not be confirmed from an official source is here, with the evidence and with what would close it. Flagged items do not block the build. They do block any claim that the property is fully underwritten.

15 items: 4 high, 7 medium, 4 low.

The high-severity items first

F01 · Repository / CI

The shared GitHub Actions check had been failing on main since 2026-11-08, so every push was red and the 'generated output is up to date' gate could never pass again.

Evidence: Workflow run 42534513123 for commit ea702c7 failed in the step 'Fail if generated files are out of date'. Reproduced locally by replaying the workflow steps in order: the only files that change are session-f4f700c0/audit/inventory.json and .../summary.json.

Action: FIXED in this session. COORDINATION.md is still read on every line for privacy and structural checks; only its stored fingerprint is withheld. Verified by running the workflow steps twice from a clean tree: git status is empty both times.

F02 · Data availability

The property's rent, exact expiry, option structure, guaranty, basis, depreciation, debt and jurisdiction are not public. They are the inputs that decide the question.

Evidence: No public source identifies the parcel. Confirmed by the absence of any address, APN or owner in the brief, which is intentional and correct for privacy.

Action: Published as labelled blanks throughout, never estimated. The decision rule in data/decisions.json is ordered so that each gate closes one of these gaps. This is the single largest limitation of every workbook on this repository.

F03 · Valuation

No value, price or cap rate for this asset is published, and none can be.

Evidence: No official body publishes transaction cap rates for individual net-lease assets. Any cap rate on this repository is an assumption.

Action: This session publishes a cost stack at a clearly labelled demonstration price and a decision rule instead of a valuation. Prior workbooks that publish dollar rankings are flagged, not endorsed.

F04 · Parcel hazards

The parcel's CAL FIRE Fire Hazard Severity Zone class, FEMA flood zone, seismic hazard zone and retrofit status are unverified.

Evidence: Each of these is a parcel-specific lookup that requires an address or APN. CAL FIRE's own page states that FHSZ maps evaluate hazard, not risk, and directs users to enter an address.

Action: Named as a required pre-sale action rather than approximated. Regional context is verified (USGS 60/46/31 given; CAL FIRE classification scheme given); the parcel answer is blank.
