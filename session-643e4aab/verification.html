Verification

The rules this workbook follows, the checks that run automatically, and the errors found and corrected.

What was checked, how, and what did not survive checking. Including the errors made in this session and corrected.

Rules this workbook follows

  1. A value is published only if it was read from the official source, linked on the same row, on 2026-11-07.
  2. If no official source exists, the cell is blank and the row is listed on Flagged for review. Nothing is inferred, interpolated, carried over from another session, or taken from an aggregator.
  3. Verified inputs live in a separate structure from analyst assumptions, and assumptions are labelled wherever a number built on them appears.
  4. The build fails if a row has a value without a source, if a "verified" row is blank, if an internal link is broken, or if a possible personal identifier appears.
  5. Every automated check is in scripts/verify.py and runs in CI on every push.

Findings about earlier work in this repository

V17 - the published root site's labour data is one release behind. The root data/metrics.json cites the BLS Los Angeles Area Economic Summary "updated October 05, 2026". The official document now on that URL is updated November 04, 2026. Several rows therefore differ, and one changes sign: root row M32 reports government employment +10.7 thousand (+1.5%); the current release shows -8.4 thousand (-1.1%). Total nonfarm employment is 6,282.1k (not 6,289.1k), the metro unemployment rate is 4.4% (not 4.8%), CPI is +3.7% (not +3.6%) and energy is +20.3% (not +17.6%). The earlier numbers were not fabricated - they were correct as of the earlier release - but they are superseded. This session used the current release. Flagged for the owner rather than edited, because the root site belongs to another session's scope.
V19 - two values were left blank by an earlier session that are actually published. The root site leaves the city poverty rate and per-capita income blank as "not present in the QuickFacts extract". Both are on the official Census QuickFacts page: per capita income $47,685 and persons in poverty 16.5% for 2020-2024/2025. They are published here as verified rows I03 and I05, each with the source linked.
V18 - an error made and corrected inside this session. The first version of model/projection.py compared "hold the property" against "invest the proceeds at a flat yield". That is not a like-for-like comparison - it pits a growing asset against a static income stream - and it produced a mechanically pro-holding answer. The model was rewritten so that a sale buys a replacement property that grows and is sold on the same terms as the subject. The corrected model is the one published. This is recorded because a model that flatters one answer is the kind of error the brief asks to be caught.
V20 - a recursion bug was found and fixed before publication. The breakeven solver called the evaluation function, which called the solver. The solver is now closed-form. Noted because it is exactly the kind of defect that would have produced a silently wrong breakeven number.

What was checked automatically

  • Every table row resolves to a source id present in data/sources.json with an https URL.
  • No row marked verified has an empty value; no row marked unverified has a value.
  • Every internal link and every navigation target resolves to a file that exists.
  • No email address, phone number, street address, parcel number, account number or Social Security number pattern appears in any generated page.
  • The model's published JSON matches what the engine regenerates byte for byte.

Scope and limitations

This is internal decision support, not an appraisal, and not investment, legal or tax advice. The parcel-level conclusions that an appraisal would supply are explicitly absent: no value is asserted, no hazard classification is claimed for the parcel, and no tax liability is computed for the owner. There are 25 such gaps and they are enumerated, each with the document that closes it.

Internal decision support for the property owner. Not an appraisal, not investment, legal or tax advice. No personal information (name, street address, parcel number, loan number, account number or tax identifiers) is published here; the subject is referred to only as the Subject Property. Every figure carries the official source it was read from on 2026-11-07, or is left blank and listed on the Flagged for review page. See Verification.
