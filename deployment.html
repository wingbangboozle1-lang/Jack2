Publish path

  1. All work on arena/742b6a03-jack2. Every commit is small and scoped.
  2. git pull --rebase before each push.
  3. Pull request from the session branch to main, with the summary, sources and flagged irregularities.
  4. Checks must pass before merge; a broken site is never merged.
  5. Merge to main. GitHub Pages serves main / root; .nojekyll keeps the files served exactly as built.
  6. The deployment status and PR link are recorded in COORDINATION.md.

Reproduce locally

python3 tools/model.py        # regenerate data/model_output.json + research/model-report.md
python3 tools/build_site.py   # regenerate all HTML pages
python3 tools/check_site.py   # links, sources, PII, orphan pages

Python 3.11, standard library only. No installs, no network access required to build.
