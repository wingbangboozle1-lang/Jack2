Executive decision framework

Sell, hold, extend—or change the asset

Do not blindly hold to expiry or assume renewal. Start a confidential market-value and buyer-interest check while reviewing the executed lease and negotiating a tenant-supported extension. Favor a sale only when an executable, same-basis net sale value exceeds a conservative hold value plus an explicit, non-duplicated uncertainty/liquidity buffer. Favor an extension only when its incremental value exceeds added landlord obligations, retained risks and the sale alternative.

Recommended process now

Run a confidential price-discovery track and an extension negotiation track in parallel. Do not wait passively for expiry, and do not sign an extension merely because it is available.

Decision thresholds

LEAN SELL: executable net sale value before debt/owner tax ≥ conservative hold PV + explicit uncertainty/liquidity buffer, after separately checking owner taxes, debt/prepayment, guarantees and reinvestment needs.

LEAN HOLD / PLAN EXIT: the sale test fails and liquidity reserves cover landlord obligations, vacancy and tail losses; reassess at each evidence update.

PURSUE EXTENSION: PV(extension) − PV(existing hold) > incremental concessions, landlord carve-outs and retained-risk burden, AND the extended position remains competitive with the sale alternative. Do not count the same risk in both the discount rate and a cash-flow/risk-buffer deduction.

NO FINAL CHOICE: any critical lease, rent, executable sale value, tenant-credit or tax/debt input remains unknown. The dashboard deliberately returns no property-specific best price.

Sell gate: net sale value (before debt / owner tax) ≥ conservative hold PV + explicit buffer
Extension gate: incremental extension value > incremental costs + retained-risk burden, and competitive with sale

Do not deduct the same risk twice. Owner-level after-tax, after-debt proceeds and reinvestment alternatives are a separate required comparison.
