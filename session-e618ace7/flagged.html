Part 3 — how the review was performed

  1. Every JSON ledger in the repository was parsed and structurally checked: duplicate ids, rows with no source, rows marked verified with an empty value, and URLs that are not https.
  2. Every source URL cited by the root build was opened and compared with the value printed on the row that cites it.
  3. Each session's headline figures were spot-checked against the primary document. Two apparent conflicts were resolved in the other sessions' favour (R-05, R-07); one framing problem was recorded (R-08).
  4. A personal-information pattern scan was run across every text file in the repository, including all six sites and the git metadata available locally.
  5. Every internal link on every page was resolved at build time.
