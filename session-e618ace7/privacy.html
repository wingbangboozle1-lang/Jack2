Privacy

Personal information is the highest priority in this brief. Nothing that could identify the Owner, the property or the tenant's lease terms is stored, transmitted or published.

What is not collected

CategoryStatus in this build
Owner name, entity, address, contact detailsNot collected, not stored, not published
Street address, APN, legal description, parcel geometryNot collected. The analysis is geography-agnostic beyond "Central Los Angeles".
Rent, NOI, purchase price, tax basis, depreciation, loan terms, lenderNot collected. All modelling is normalised per $100,000 of annual NOI.
Tenant lease document, rent schedule, guaranteesNot collected
Insurance policy numbers, carrier, account numbersNot collected
Any individual's income, net worth or tax returnNot collected. The model never asks for it.

How that is enforced rather than promised

  • The data files contain no free-text field where such information could be pasted. Fact rows carry a metric, a value read from a public source, and a source id.
  • The build script scans every generated file for email addresses, phone numbers, parcel-number patterns and street-address patterns, and fails the build on a match.
  • No analytics, no cookies, no fonts, no scripts and no third-party requests are loaded by any page. The site is static HTML and one stylesheet.
  • No form, no input field and no upload exists anywhere on the site, so no personal data can be entered.

What the site does contain

Public facts about a public company (Jack in the Box Inc., a Nasdaq issuer), public statistics about Los Angeles, and public tax and hazard rules. All of it is already published by the government. None of it is personal.

Retention

The repository is public because it publishes to GitHub Pages. Anything private that the Owner later supplies should be kept out of this repository entirely and, if it must be analysed, summarised only as a derived ratio — the same technique used here.

If you are the Owner: you never need to send the address, the rent or your tax return for this workbook to be useful. The decision rule is expressed in terms you can apply yourself: years of remaining term, rent versus market, and the exit tax.
