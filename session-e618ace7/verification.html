The rules this build enforces in code

  1. A row with a value must carry a source id that exists in sources.json and whose URL begins with https://. The build fails otherwise.
  2. A row marked unverified must have an empty value cell. The build fails if a value appears there.
  3. Every source URL is printed on the row that relies on it, not collected on a separate page.
  4. Every page carries the privacy and scope notices, and the build fails if an email address, phone number, parcel-number pattern or street-address pattern appears in any generated file.
  5. Internal links are resolved at build time; a broken internal link fails the build.
  6. The model is deterministic. The Monte Carlo is seeded, so a rebuild produces byte-identical output.

What "verified" does not mean

It means the number was read from the named official document on 2026-11-07. It does not mean the document is correct, current, or applicable to this parcel. Four specific limits apply:

  • Vintage. Employment data are preliminary and revised. The Census ACS is a five-year rolling estimate. Both are current as of the access date and will move.
  • Geography. City, county and metro figures are used because the sub-market is withheld. A specific corner in Central Los Angeles can differ materially from the county average.
  • Parcel specificity. Nothing parcel-level is asserted. Fire zone, flood zone, seismic class and insurance terms are all blank.
  • Official does not mean advice. Tax rules quoted here are statutory references, not a computation of the Owner's liability.
