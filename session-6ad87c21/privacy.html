Privacy

What is withheld, what is never collected, and how the control is enforced in code rather than promised in prose.

No personal information is published on this site. Not the owner's name, not the property address, not the assessor parcel number, not the rent, not the purchase basis, not any loan or account number. The site describes a “Central Los Angeles” single-tenant restaurant and expresses every financial result per $100,000 of net operating income.

What is withheld, and how

ItemHandling
Owner identityNot collected. Never appears. Placeholder [REDACTED-OWNER-01] where an identifier would otherwise be required.
Property addressNot collected. Placeholder [REDACTED-PROPERTY-01]. Geography is limited to City / County / metro.
Assessor parcel numberNot collected. Placeholder [REDACTED-PARCEL-01].
In-place rent, escalations, percentage rentNot collected. The model is normalised to $100,000 of NOI, so the private figure is never needed.
Purchase basis and depreciationNot collected. The after-tax model uses a published basis ratio (A6) and tests the range instead.
Loan balance, rate, lenderNot collected. Listed as an unknown to obtain.
Tenant legal entity and guarantorNot collected. Described only as “likely a franchisee” because 93% of the system is franchised.

The one personal identifier that does exist in this repository

The git commit history contains the repository owner's personal email address in the author metadata of every commit. That is a property of how the repository was created, not of this site, and it is published on the Flagged for Review page as I-01 with the recommended fix (enable GitHub's email-privacy setting; history rewriting is not attempted because it would invalidate every prior session's commit references). No other personal identifier was found in a scan of the repository's HTML, JSON, Markdown and Python files.

How the control is enforced, not just promised

  • scripts/verify.py scans every generated page and every data file for email addresses, telephone numbers, US street-address patterns, assessor parcel numbers, and the placeholder-free mention of the owner or the tenant entity.
  • The build fails if the scan matches. It is not a manual promise that the site is clean — it is a test that runs on every build and can be re-run by anyone.
  • The fact ledger uses a dedicated status for private facts (owner) so that they cannot be confused with verified public data, and unverified facts are structurally incapable of carrying a value.

If you believe something private has been published

Report it immediately and treat it as a defect. The correct response is to remove the page from publication first and investigate second. Nothing on this site is worth publishing at the cost of the owner's privacy.
