Sources

The complete ledger: every official record used, its tier, and what it supports.

Every value published on this site was read from one of these 17 sources on 2026-11-08. A source is listed here only if it was actually opened and read during this session — no citation was copied from another document, and no value came from a data aggregator.

Tiers. A = primary official government or regulator record. B = primary issuer filing with a securities regulator. C = analyst assumption published by this workbook and never presented as a fact. D = secondary or commercial commentary, used for orientation only and never for a published value. No tier D source is used for any number on this site.

What is deliberately absent from this list

  • Commercial brokerage research, cap-rate surveys and news articles. They are useful orientation but they are not official records, so no value on this site depends on them.
  • Aggregator statistics. Where an official series exists, the official series is cited; where it does not, the value is blank.
  • Anything the owner did not supply and that is not public: rent, basis, loan terms, the lease itself, the franchisee's financials.

Reproducing the verification

Each fact row on the site carries its source id and that id resolves to the URL above. The automated checker re-tests every row: a verified or computed fact must resolve to a URL in this ledger, an unverified fact must be blank, every internal link must exist, and a personal-information scan must return nothing. Run python3 session-6ad87c21/scripts/verify.py.
