# Jack2 — DTLA NNN Asset Intelligence

Executive decision analysis and GitHub Pages site for a single-tenant **Jack in the Box**
restaurant pad (Central Los Angeles) on a **triple-net (NNN) lease** expiring **2030–2035**:
sell before expiry, or renew?

- **Live site:** https://wingbangboozle1-lang.github.io/Jack2/ (GitHub Pages, served from `main` root)
- Start at the **Executive Summary** on the dashboard, then **Sell vs Renew** for the recommendation,
  **Risk Register** for routine and black-swan risk, and **Sources & Verification** for every link.
- Private owner/property data is anonymized behind `[PLACEHOLDERS]`; **no personal information is published**.

## Verification standard

Every value is marked Verified / Reported / Computed / Flagged / Placeholder.
Unverified values are left blank or flagged — never inferred. See `sources.html` for the protocol.
