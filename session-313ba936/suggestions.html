Suggestions and review

Suggestions — review before implementing any change

Analyst proposals for improving this workbook's decision-making coverage and for closing the information gaps that block a binding decision. None of these is a measured value; each is a proposed action with a priority and a suggested owner. Review and approve here before touching the model, the data, or the site.

How to use this page

Each suggestion below is a proposed change to the workbook, the model, or the owner's information-gathering. Read the rationale, check the priority, and decide whether to adopt it. Approved suggestions are implemented by editing the data files or the build script, then re-running build_site.py and verify.py. No suggestion is live until it has been re-verified.

Review before implementing. Changing an assumption, a weight, a cap rate, or a source can move the breakevens and flip the recommendation. Treat every suggestion as a hypothesis: adopt it, re-run the model, and confirm the decision still holds before publishing.

Suggested review and approval sequence

  1. Read this page and mark each suggestion adopt / defer / reject.
  2. Adopted suggestions are implemented by editing data files or scripts only — never by hand-editing HTML.
  3. Re-run python3 session-313ba936/scripts/build_site.py and python3 session-313ba936/scripts/verify.py.
  4. Confirm all 20 verification checks pass before publishing.
  5. Commit the changed data and scripts together with the regenerated HTML in one pull request.
  6. Review the merged result on GitHub Pages before making any decision based on it.

Standing rule. No suggestion changes a published number until the model has been re-run, the breakevens re-checked, and all 20 verification checks pass. A suggestion that moves the breakeven cap or the replacement yield is a decision-changing change — treat it with the same scrutiny as the original model.

What is deliberately NOT a suggestion

  • This page does not suggest a property value — the rent is unknown, so a value would be an invention.
  • This page does not suggest a capital-gains rate — that depends on the owner's basis and filing status.
  • This page does not suggest the parcel address or APN — personal and parcel-identifying information is excluded by construction (see Privacy).
