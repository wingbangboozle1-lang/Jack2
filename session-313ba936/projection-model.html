Every assumption, with its reason

This is the table to attack. If one of these is wrong, the answer moves, and the owner should replace it with a real number.

InputValueWhy this value, and how wrong it could be
rent_normaliser100000 USD per yearContract rent is unknown (metric L02). Every result is per $100,000 of rent so the owner can scale linearly to their actual rent.
going_in_cap_pct6.8 %The asset's own cap rate is unpublished (M11). Set equal to the verified Q3 2026 net-lease acquisition cash yield (S17) as the neutral central case. This single number is the one the owner must replace with an appraisal.
expiry_year2032 yearMidpoint of the 2030-2035 window the brief supplies. The exact date is unverified (L01).
horizon_year2040 yearCovers the remaining term plus a full renewal cycle.
escalation_pct2.0 % per yearTypical flat net-lease escalation. The lease was not read (L03).
terminal_cap_pct6.8 %No cap-rate change assumed over the horizon.
brokerage_pct3.0 %Negotiated, not published (X13).
closing_pct0.5 %Title, escrow, legal, diligence. Negotiated.
renew_prob0.75 probabilityNo official source exists. Balances a live closure programme (R02) against a site the brand occupies.
downtime_months_if_vacated12 monthsA drive-through site can only be re-let to entitlement-compatible uses.
relet_cost_pct_of_year_rent5.0 %Leasing commission plus tenant improvements on a small-format asset.
insurance_recovery_pct60.0 % of hazard lossCoverage after deductible and limits. The actual policy is unknown (H11, H12).
fire_annual_prob_pct0.5 % per yearLABELLED ASSUMPTION, NOT OFFICIAL. CAL FIRE publishes hazard zones and loss history (S19, S20) but no parcel annual burn probability. Set low because the parcel is urban; flagged on flag.html.
rate_shock_annual_prob_pct4.0 % per yearLabelled assumption for a +150bp permanent cap-rate widening.
rate_shock_bp150 basis pointsLabelled assumption for the size.
uplift_at_renewal_pct0.0 %Central case assumes renewal at the escalated contract rent, i.e. no reset. The breakeven uplift is solved for separately.

Two assumptions are not like the others. fire_annual_prob_pct is set at 0.5% a year with no official annual per-parcel burn probability behind it, and going_in_cap_pct is set equal to a portfolio average rather than an appraisal of this asset. Both are flagged on Flagged for review.

Reproduction

python3 session-313ba936/scripts/model.py        # engine, deterministic, no network
python3 session-313ba936/scripts/build_site.py   # this site
python3 session-313ba936/scripts/verify.py       # line-level checks

Comparison basis: Holding and selling run through the same cash-flow engine with the same escalation, reinvestment rate and exit cap. The sale pays transaction costs and the replacement is bought at the verified net-lease market yield. This is a like-for-like comparison; an earlier version of this script compared a growing asset to a non-growing yield, which is recorded as irregularity F02.

Internal decision support. Not an appraisal, not tax advice, not investment advice. Every value on this page is read from the official source linked beside it on 2026-11-10. Values that could not be confirmed are blank and listed on Flagged for review.
